# v0.2.7 Release Notes

> Released: 2026-09-23
> `desktop-v0.2.7` · `@taco-ai/{protocol,shared,sidecar,cli}@0.2.7`

Subagents can now run in the background without blocking the current turn, be stopped individually without cancelling the whole run, and their results no longer get lost after a restart or a missed notification. Alongside that: shell commands that ignore a stop signal no longer hang forever, repeated turns get cheaper by no longer invalidating the prompt cache, and long chat sessions keep their memory content after compaction.

---

## English

### Features

- **Subagents can run in the background** — a subagent no longer has to block the current turn; it keeps running after the tool call returns, and its result arrives later once it's done — `sidecar` + `protocol`
- **Stop one subagent without aborting the whole run** — the desktop subagent panel gets a Stop button that cancels a single background subagent; a stopped subagent now shows as "stopped" instead of an error — `sidecar` + `protocol` + `shared` + `desktop`
- **Background subagent results no longer get lost** — a subagent's result now survives a sidecar restart or a parent session that was never reopened in time to catch the live notification — `sidecar`

### Improvements

- **Subagent card now shows the correct status in more cases** — a subagent interrupted before finishing now shows as an error instead of quietly appearing complete, and the card no longer gets stuck showing "running" after it's actually done — `sidecar` + `shared` + `desktop`
- **Lower cost on repeated turns** — a change to how live context is added to prompts stops it from invalidating the provider's prompt cache on every turn — `sidecar` + `protocol` + `desktop`
- **Better code review quality** — the reviewer agent is now better at catching itself when it's tempted to wave through a shortcut instead of flagging it — `sidecar`
- Routine dependency upgrade and internal cleanup, no user-facing behavior change — `sidecar` + `desktop`

### Fixes

- **Shell commands that ignore a stop signal no longer hang** — a command that caught or ignored `SIGTERM` could freeze its tool call indefinitely, including when the user tried to cancel it — `sidecar`
- **Long-running chat memory no longer disappears after the first compaction** — the `memory` skill was being dropped after its first use instead of staying available for the whole conversation — `sidecar`
- **Subagent no longer misreported as failed after it already succeeded** — a delivery hiccup could overwrite an already-successful subagent result with a spurious failure — `sidecar`
- **Session and subagent previews now open when using a custom data folder** — previews under a custom `TACO_HOME` location used to fail silently with no error message — `desktop`
- **Stopping a subagent now shows correctly in the panel** — a subagent the user deliberately stopped was incorrectly displayed as a normal green completion — `protocol` + `sidecar` + `desktop`
- Additional reliability fixes so background subagent notifications don't get dropped or duplicated under concurrent activity — `sidecar`

### Desktop

- **Thinking block no longer takes over the screen** — streaming "thinking" text now stays within a fixed-height preview instead of growing indefinitely, with an option to expand and read the full text — `desktop`

## 中文

### 新功能

- **子代理可在后台运行** —— 子代理不再需要阻塞当前轮次,工具调用返回后它会继续在后台运行,完成后再把结果送回来 — `sidecar` + `protocol`
- **可单独停止一个子代理,不影响整体运行** —— 桌面端子代理面板新增 Stop 按钮,可以取消某一个后台子代理;被停止的子代理现在显示为"已停止",而不是错误 — `sidecar` + `protocol` + `shared` + `desktop`
- **后台子代理的结果不再丢失** —— 即便 sidecar 重启,或父会话没能及时重新打开去接收实时通知,子代理的结果现在也能正常拿到 — `sidecar`

### 优化

- **子代理卡片的状态显示更准确** —— 子代理在完成前被中断时,现在会正确显示为错误,而不是看起来悄悄地完成了;卡片也不会再卡在"运行中"不刷新 — `sidecar` + `shared` + `desktop`
- **降低重复轮次的成本** —— 调整了实时上下文信息拼入 prompt 的方式,不再导致每一轮都命不中 provider 的 prompt 缓存 — `sidecar` + `protocol` + `desktop`
- **代码审查质量提升** —— reviewer agent 现在更容易识别并拒绝"想放水收尾"的走捷径倾向,而不是被带偏 — `sidecar`
- 常规依赖升级与内部清理,无用户可感知的行为变化 — `sidecar` + `desktop`

### 修复

- **忽略停止信号的 shell 命令不再卡死** —— 捕获或忽略 `SIGTERM` 的命令之前可能无限期挂住工具调用,连用户主动取消都不管用 — `sidecar`
- **长对话中的记忆内容不会在第一次压缩后消失** —— `memory` skill 之前只在第一次使用后就被丢弃,而不是在整个对话过程中持续可用 — `sidecar`
- **子代理成功执行后不会被误报为失败** —— 一次送达环节的小故障之前可能覆盖掉已经成功的子代理结果,误报为失败 — `sidecar`
- **使用自定义数据目录时,会话/子代理预览现在能正常打开** —— 之前在自定义 `TACO_HOME` 路径下预览会静默失败,且没有任何报错提示 — `desktop`
- **停止子代理后面板显示正确了** —— 用户主动停止的子代理之前会被错误地显示为正常的绿色完成状态 — `protocol` + `sidecar` + `desktop`
- 其他可靠性修复:高并发场景下,后台子代理的通知不再丢失或重复 — `sidecar`

### 桌面端

- **Thinking 块不再无限占屏** —— 流式输出的"思考"内容现在保持在固定高度的预览区内,不会无限撑高;需要时可以点开看完整内容 — `desktop`

## Upgrade notes

- Workspace versions advance `0.2.6 → 0.2.7` across `desktop`, `protocol`, `shared`, `sidecar`, and `cli`. Keep the desktop and sidecar on the same release line, as before.
- Wire protocol stays at 2.1 — this release only adds new optional fields/types, nothing existing was removed or narrowed.
- A subagent left dangling before this release (interrupted by a restart or a missed notification) will now be picked up and reported correctly the next time its parent is opened — previously it could be silently dropped.
- Subagents stopped via the new Stop button now report as "stopped", distinct from both a normal completion and an error; any UI or automation matching on subagent outcome strings should account for this new variant.
