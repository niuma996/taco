# v0.2.5 Release Notes

> Released: 2026-09-19
> `desktop-v0.2.5` · `@taco-ai/{protocol,shared,sidecar,cli}@0.2.5`

Subagent runs now stream live progress and checkpoint a resumable child session, compaction is driven end-to-end from the sidecar lifecycle with a one-call compact and a desktop trigger on the context-usage ring, and skill pinning survives compaction after a tag-parsing fix. The session list no longer shows subagent children or clusters every old session at "just now", and read-only subagents can run the usual git inspection commands without a permission prompt.

---

## English

### Features

- **Streamed subagent progress + resumable child session checkpoint** — a durable recovery handle is published as soon as a subagent's child session exists, and live turn updates fold into the running tool card, so an interrupted `agent`/`skill` call can resume via `agentContinue` and the desktop can open the child session mid-run — `sidecar` + `desktop`
- **Compact button on the context-usage ring** — the popover on the prompt-bar ring now triggers `session.compact` below the auto threshold, disabled while a turn or compaction is already in flight — `desktop`

### Improvements

- **Compaction driven from sidecar lifecycle and shared settings** — the sidecar now owns the compaction start/end pair directly (pi 0.85 dropped the old before/after hooks) and derives `CompactionSettings` from the user's threshold for every compaction path; completed-but-unreadable entries surface as `harness_error` so the RPC and toast agree — `sidecar` + `desktop`
- **Compaction collapsed to one LLM call** — dropped the second fact-extraction call; the pin directive now rides pi's Additional-focus slot instead of a conversation preface, with the verbatim `PINNED` tail kept after the summary — `sidecar`
- **Subagent progress sourced from turn events** — per-turn updates read the assistant message off `turn_end` instead of re-reading the child's branch, removing a session read per turn and the ordering window where a slow read could publish stale text; progress details get their own protocol type so a final result can't be mistaken for a running one — `sidecar` + `desktop`
- **Read-only git inspection no longer prompts** — the read-only shell broker used by `explorer` / `reviewer` now auto-allows the common inspection verbs (`git blame`, `git rev-parse`, `git ls-files`, `git merge-base`, `git describe`, …) plus the read-only forms of dual-use parents (`git stash list`, `git config --get`, `git tag --list`, `git worktree list`). Mutating siblings still ask: flag checks match on the stem so an attached value can't slip through, and `git branch` / `git remote` reject positional arguments that would create a branch or contact the remote — `sidecar`

### Fixes

- **`skill_body` parsed as XML attributes, each skill pinned individually** — the colon-form `<skill_body:NAME>` tag wasn't balanced XML, so pin, TUI hide, and the reinjector couldn't see it; it's now emitted as `<skill_body name="…">` with per-name dedupe so multiple pinned skills survive compaction — `sidecar`
- **Subagent sessions hidden from the list, sorted by last message** — pi 0.85 dropped the free-form metadata bag, so `session.list` treated unfacted children as top-level sessions; children are now identified by kind, header `parentSessionId`, and restored v3 facts, with facts backfilled ahead of a v3→v4 rewrite. `updatedAt` comes from the last user-visible message instead of file mtime, so upgrading no longer stamps every old session as "just now" — `sidecar`
- **Subagent panel message wrapping** — reused chat bubbles inherited the main-chat gutters and the stream lacked column flex, so user bubbles didn't right-align and long unbroken tokens widened the panel — `desktop`

## 中文

### 新功能

- **Subagent 进度实时流式 + 可恢复的子会话 checkpoint** —— 子会话一创建就发布持久化的恢复句柄,实时的 turn 更新会并入运行中的工具卡片;被中断的 `agent`/`skill` 调用可以通过 `agentContinue` 恢复,桌面端也能在子任务运行过程中打开子会话 — `sidecar` + `desktop`
- **Context 用量环上新增 Compact 按钮** —— prompt 栏用量环的弹出面板现在可以在低于自动阈值时主动触发 `session.compact`,turn 或压缩进行中时按钮禁用 — `desktop`

### 优化

- **压缩改由 sidecar 生命周期与共享设置驱动** —— pi 0.85 去掉了旧的 compact 前后 hook,sidecar 现在直接管理压缩的 start/end 配对,并为每条压缩路径根据用户阈值推导 `CompactionSettings`;完成但不可读的条目统一归为 `harness_error`,让 RPC 与 toast 提示保持一致 — `sidecar` + `desktop`
- **压缩收拢为单次 LLM 调用** —— 去掉了第二次 fact-extraction 调用;pin 指令改走 pi 的 Additional focus 位,不再插入对话前言,摘要后仍保留原样的 `PINNED` 尾部 — `sidecar`
- **Subagent 进度改从 turn 事件取数** —— 每个 turn 的更新直接从 `turn_end` 读取 assistant 消息,不再重读子会话分支,省掉每个 turn 一次的会话读取,也消除了慢读可能发布过期文本的时间窗;进度详情拥有独立的协议类型,最终结果不会再被误判为运行中 — `sidecar` + `desktop`
- **只读 git 查看类命令不再弹权限确认** —— `explorer` / `reviewer` 使用的只读 shell broker 现在自动放行常用的查看类命令(`git blame`、`git rev-parse`、`git ls-files`、`git merge-base`、`git describe` 等),以及 dual-use 命令的只读形式(`git stash list`、`git config --get`、`git tag --list`、`git worktree list`)。会改动状态的同族命令仍然需要确认:flag 检查按词干匹配,带等号的取值无法绕过;`git branch` / `git remote` 会拒绝那些能建分支或连远端的位置参数 — `sidecar`

### 修复

- **`skill_body` 改为 XML 属性解析,逐个 skill 单独 pin** —— 冒号形式的 `<skill_body:NAME>` 标签不是合法闭合的 XML,导致 pin、TUI 隐藏与 reinjector 都看不到它;现在改为 `<skill_body name="…">` 并按 name 去重,多个被 pin 的 skill 能在压缩后存活 — `sidecar`
- **Subagent 会话不再出现在列表中,并按最后一条消息排序** —— pi 0.85 去掉了自由格式的 metadata,导致 `session.list` 把缺少 facts 的子会话当成顶层会话;现在通过 kind、header 里的 `parentSessionId` 与恢复出的 v3 facts 共同判定子会话,并在 v3→v4 重写之前回填 facts。`updatedAt` 改用最后一条用户可见消息的时间而非文件 mtime,升级后不会再把所有旧会话都标成"刚刚" — `sidecar`
- **Subagent 面板消息换行修复** —— 复用的聊天气泡继承了主聊天区的外边距,加上消息流缺少纵向 flex,导致用户气泡没有右对齐、过长的连续字符会把面板撑宽 — `desktop`

## Upgrade notes

- Workspace versions advance `0.2.4 → 0.2.5` across `desktop`, `protocol`, `shared`, `sidecar`, and `cli`. Keep the desktop and sidecar on the same release line, as before.
- Wire protocol stays at 2.1 — no breaking change for downstream consumers, though `progress` details now carry their own protocol type distinct from a final result.
- Compaction behavior changed under the hood (single LLM call, pin via `customInstructions`, lifecycle owned by the sidecar) but the user-facing `session.compact` RPC and settings shape are unchanged.
- Skills pinned via `<skill_body>` before this release should be re-verified after upgrading — the tag shape changed from colon-suffixed to an XML attribute.
- Sessions created before this release are re-read on first list: subagent children drop out of the list and `updatedAt` is recomputed from the last user-visible message, so existing sessions may reorder once.
- The read-only shell allowlist grew, so `explorer` / `reviewer` now run more git inspection commands without prompting. Anything that mutates state still asks.
