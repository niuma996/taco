# v0.1.2 Release Notes

> Released: 2026-09-01
> `desktop-v0.1.2` · `@taco-ai/{protocol,shared,sidecar,cli}@0.1.2`

---

## English

### Features

- `context: fork` subagent capability with frontmatter-driven hints — `sidecar`
- Agent tool hints derived from `AgentDefinition`; reviewer builtin ships with `context: fork` — `sidecar`

### Improvements

- Test suite reorganized: dedupe + logger merged, checkpoint store + manager merged, stale cases dropped — `sidecar` + `desktop`
- Cold-start hardening replayed; long inline JSDoc blocks trimmed under repo style guide — `all`
- `AgentSpawner.prepareChildAttach()` shared between spawn and resume paths — `sidecar`

### Fixes

- MCP card visibility, channels centering, border tokens polished — `desktop`
- `mcp.*` mutations apply without sidecar restart — `sidecar` + `desktop`
- `stderrTee` error listeners removed on dispose — `sidecar`
- `tacoClient.wait-for-initialize` test flushes microtask before asserting — `desktop`
- Subagent `parentInstructionsBlock` snapshot replaced with lazy thunk — `sidecar`

## 中文

### 新功能

- `context: fork` 子代理能力，通过 frontmatter 驱动 hints — `sidecar`
- Agent tool hints 由 `AgentDefinition` 派生；reviewer 内置走 `context: fork` — `sidecar`

### 优化

- 测试整理：dedupe + logger 合并、checkpoint store + manager 合并、删除陈旧用例 — `sidecar` + `desktop`
- 重放冷启动加固；内联 JSDoc 长块注释按仓库风格修剪 — `all`
- `AgentSpawner.prepareChildAttach()` 在 spawn 与 resume 共用 — `sidecar`

### 修复

- MCP 卡片可见性、Channels 居中、边框 token 优化 — `desktop`
- `mcp.*` 变更无需重启 sidecar — `sidecar` + `desktop`
- `stderrTee` dispose 时移除 error 监听 — `sidecar`
- `tacoClient.wait-for-initialize` 测试断言前 flush 微任务 — `desktop`
- 子代理 `parentInstructionsBlock` 改为 lazy thunk — `sidecar`
