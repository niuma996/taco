# v0.2.3 Release Notes

> Released: 2026-09-16
> `desktop-v0.2.3` · `@taco-ai/{protocol,shared,sidecar,cli}@0.2.3`

Right-rail subagent panel ships as a first-class side panel, sidecar's runtime is split by concern with mutable config flowing through thunks, and protocol brands its IDs so the wrong one fails at compile time.

---

## English

### Features

- **Subagent side panel in the right rail** — adds a subagent panel alongside the existing Tasks / Files drawer; the agent card becomes the panel's entry point, the rail width is now drag-resizable, and the panel list is derived straight from the message stream so it stays in sync without per-source invalidation plumbing — `desktop`
- **Absolute-path fence + real compaction cancel** — unknown tools now reject absolute paths at the fence; a request to cancel compaction is no longer silently dropped, so the turn genuinely unwinds instead of finishing the work behind the user's back — `sidecar`

### Improvements

- **Derived state moves to thunks** — long-lived consumers no longer hold a snapshot of mutable config; they receive a `resolveX: () => X` and re-resolve on each use, with a name-comparison guard that keeps steady-state prompts byte-identical so the model's KV-cache prefix stays warm — `sidecar`
- **`runtime/` split by concern + `withDeadline` for capability timeouts** — sidecar's internal runtime is broken into channel control surface, skill hot reload, and helper modules; every "wait for an async capability" path now goes through one `withDeadline`, so timeouts are configured in one place — `sidecar`
- **`WorkspaceId` / `SessionId` / `ToolCallId` branded** — protocol gives these IDs nominal types so passing the wrong ID across a module boundary is a compile-time error — `protocol`
- **Right-rail exclusivity collapses to one value** — Tasks / Files / Subagent exclusivity is owned by a single state source instead of three places racing each other — `desktop`

### Fixes

- **`SubagentPanel` mounted inside `SubagentProvider`** — was being rendered outside, so the panel's context wasn't always stable; the subagent button's surfacing condition is corrected at the same time, and the drag handle now keeps the rail width inside a moving bound so it cannot be squashed to zero or pushed off-screen — `desktop`
- **Push seq stays continuous across a sidecar restart** — the sequence number no longer resets on restart, so reconnecting clients don't see spurious gaps in the event stream — `sidecar`
- **Onboarding gated on a settled flag, not a non-empty cwd** — onboarding no longer fires when a transient `cwd` happens to be non-empty; `OnboardingModal` opens on `defaultCwd` settling and `ProviderSection` re-syncs when `globalConfig` updates — `desktop`

## 中文

### 新功能

- **右栏 subagent 侧边面板** —— 在现有 Tasks / Files 抽屉旁新增 subagent 面板；agent card 作为入口，右栏宽度可拖拽；面板列表直接从消息流派生，跟源同步无需按源失效 — `desktop`
- **绝对路径越界保护 + compaction 真取消** —— 未知工具接到绝对路径会在 fence 处被拒；compaction 的取消请求不再被悄悄丢弃，turn 真能展开回退，不会在用户视野之外把工作做完 — `sidecar`

### 优化

- **派生状态走 thunks** —— 长生命周期 consumer 不再持有 mutable config 快照，改为接收 `resolveX: () => X`，每次使用都重新解析；name-comparison 守卫确保稳态 prompt 字节一致，模型 KV-cache prefix 不抖动 — `sidecar`
- **`runtime/` 按关注点拆分 + `withDeadline` 统一超时** —— sidecar 内部 runtime 拆成 channel control surface / skill 热重载 / helper modules；所有"等异步能力"接口统一走 `withDeadline`，超时配置集中管理 — `sidecar`
- **`WorkspaceId` / `SessionId` / `ToolCallId` 品牌化** —— protocol 给这三个 ID 加 nominal 类型，跨模块传错 ID 在编译期就报错 — `protocol`
- **右栏互斥收敛到一个值** —— Tasks / Files / Subagent 互斥显示收成一个状态源，不再三处分管相互竞争 — `desktop`

### 修复

- **`SubagentPanel` 挂在 `SubagentProvider` 内** —— 之前挂在外面导致面板上下文不稳定；同步修复 subagent 按钮浮出条件；拖拽时右栏宽度保持在合理区间，不会被压成零或推出屏外 — `desktop`
- **Sidecar restart 后 push seq 续号** —— 重启后 push 序号连续不断，reconnecting 客户端不会因序号 gap 误判丢消息 — `sidecar`
- **Onboarding 由 settled flag 触发** —— 不再以"非空 cwd"作为触发条件，避免临时 cwd 误触发；`OnboardingModal` 在 `defaultCwd` settled 时打开，`ProviderSection` 跟 `globalConfig` 更新同步 — `desktop`

## Upgrade notes

- Wire protocol stays at 2.1 — no breaking change for downstream consumers.
- Workspace versions advance `0.2.2 → 0.2.3` across `desktop`, `protocol`, `shared`, `sidecar`, and `cli`. Keep the desktop and sidecar on the same release line, as before.
- The new subagent panel is additive: it joins the existing Tasks / Files drawer as a third entry in the right rail. Existing rail behavior is preserved — the rail just gains one more thing it can show.
- The branded ID types are a type-layer change only; the runtime wire format is unchanged. Downstream code that previously used raw `string` aliases for `WorkspaceId` / `SessionId` / `ToolCallId` will need to construct values via the new nominal entry points (or `as` from a known-typed source); `pack-smoke`'s TypeScript consumer check confirms the published types still compile against the public exports.
- `max_runs` and `max_consecutive_failures` defaults from 0.2.2 are unchanged.
