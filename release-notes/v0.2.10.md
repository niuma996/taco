# v0.2.10 Release Notes

> Released: 2026-10-16
> `desktop-v0.2.10` · `@taco-ai/{protocol,shared,sidecar,cli}@0.2.10`

A one-line fix: the input box goes back to the bottom of the window, where it belongs.

---

## English

### Fixes

- **The input box stays at the bottom of the window** — since 0.2.9 it scrolled along with the messages, which held it down only while the conversation was long enough to fill the pane; in a short conversation it floated right under the last message, halfway up the window — `desktop`

---

## 中文

### 修复

- **输入框重新固定在窗口底部** —— 自 0.2.9 起它跟着消息一起滚动，只有对话长到撑满面板时才被钉在底部；对话很短时，它就浮在最后一条消息下面，停在窗口半腰 — `desktop`

---

## Upgrade notes

- Workspace versions advance `0.2.9 → 0.2.10` across `desktop`, `protocol`, `shared`, `sidecar`, and `cli`.
- Wire protocol stays at **2.1**. No RPC method, push frame, or schema changed.
- If you skipped 0.2.9, there is nothing here for you — the input box never left the bottom on your build.
