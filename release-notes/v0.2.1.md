# v0.2.1 Release Notes

> Released: 2026-09-11
> `desktop-v0.2.1` · `@taco-ai/{protocol,shared,sidecar,cli}@0.2.1`

A small follow-up to 0.2.0: two new built-in skills, manual sidecar restart from the desktop, and the read-only allowlist grows to cover the shell toolbox the model actually uses.

---

## English

### Features

- **`officecli`** ships as a built-in extension (`@taco/builtin-officecli`) that bundles the skill and allowlists the `officecli` shell commands in memory, so Office-document workflows don't prompt on every `add` / `set` / `view`; disabling the extension drops the skill and the allowlist together — `sidecar`
- **`taco-configure`** skill — the umbrella for non-skill-authoring config: remote skill install, agent authoring, and atomic patches to `$TACO_HOME/taco.json` — `sidecar`
- Manual sidecar restart from **Settings → App** — replaces `taco stop && taco start` when the daemon's bounded reconnect ladder gives up — `desktop`
- Decisions route through `askUser` instead of prose questions, and command denials are no longer re-routed to the same outcome via a different command — `sidecar`

### Improvements

- Read-only allowlist grows to cover the everyday shell toolbox — file inspection, text search, and hashing — plus `find` with safe predicates; `find` flags that write files or spawn commands still trip the ask gate — `sidecar`

### Fixes

- Files drawer toggle stays visible on the new-chat splash; images inside the drawer preview inline — `desktop`
- `channels.list` and `channels.create` share the same view of configured instances — `sidecar`
- `{subagent_delegation}` markers no longer leak into the rendered system prompt — `sidecar`

## 中文

### 新功能

- **`officecli`** 以内置扩展 `@taco/builtin-officecli` 的形式随 sidecar 打包：skill 与放行规则由同一个扩展提供，`officecli` 的 shell 命令在内存中被放行，Office 文档工作流不再逐条弹窗；禁用该扩展时 skill 与放行规则一并消失 — `sidecar`
- **`taco-configure`** skill —— 除 skill 写作之外的总入口，覆盖远程 skill 安装、agent 写作、以及 `$TACO_HOME/taco.json` 的原子补丁 — `sidecar`
- **Settings → 应用** 中可手动重启 sidecar —— 当 daemon 的有限次重连耗尽后，免去开终端跑 `taco stop && taco start` — `desktop`
- 决策统一走 `askUser`，不再用正文提问；命令被拒绝后不再通过其他路径达成同一目标 — `sidecar`

### 优化

- read-only 白名单扩到日常 shell 工具箱 —— 文件查看、文本检索、哈希 —— 以及带安全谓词的 `find`；会写文件或起进程的 `find` 谓词仍触发 ask 闸 — `sidecar`

### 修复

- files drawer 切换按钮在新聊天欢迎页仍然可见，drawer 内图片改为内联预览 — `desktop`
- `channels.list` 与 `channels.create` 视图统一，不再撞「channel already exists」 — `sidecar`
- `{subagent_delegation}` 占位符不再泄漏到渲染后的系统提示 — `sidecar`

---

## Upgrade notes

- Workspace versions advance `0.2.0 → 0.2.1`. The wire protocol is unchanged.
- The two new built-in skills (`officecli`, `taco-configure`) follow the same first-wins collision rule as every other built-in skill — user copies in higher-priority directories win on lookup. `officecli` ships with the `@taco/builtin-officecli` extension, so adding it to `disabledExtensions` removes both the skill and its shell allowlist while a user-installed copy under `~/.claude/skills` is unaffected.
