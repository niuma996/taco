# v0.4.2 Release Notes

> Released: 2026-11-16
> `desktop-v0.4.2` · `@taco-ai/{protocol,shared,sidecar,cli}@0.4.2`

This release is about the plugin system: every extension gets a real settings
surface, built-in plugins become configurable, and the runtime now isolates a
broken or conflicting third-party extension instead of letting it take the
workspace down.

---

## English

### Features

- **Plugins have their own settings dialog** — plugin details and settings open
  in a separate dialog. Supported scalar/enum settings are rendered from the
  plugin's own schema with localized, plugin-owned labels; saving writes only
  the fields you changed, and a restart applies them — `sidecar` + `desktop`
- **Built-in plugins are configurable** — Git context, project manifests,
  OfficeCLI and output redaction gain validated configuration and workspace
  activation diagnostics. Git/project context is recognized even after the
  project is initialized mid-session, and the OfficeCLI skill and command
  approval are now independent options — `sidecar` + `desktop`

### Improvements

- **A broken or conflicting extension no longer takes the workspace down** —
  the extension runtime gains atomic rollback, workspace activators, lazy tools,
  and file-access declarations. A failing tool candidate is skipped with its
  name logged, a tool name colliding with a built-in tool is dropped instead of
  failing every session, and one extension can no longer remove another's
  file-access declaration — `sidecar` + `desktop`
- **Extensions get scoped lifecycles and honest diagnostics** — workspace and
  session activators with completion events and deterministic cleanup, per-
  extension configuration validation, and status that distinguishes actual
  contributions from changes still waiting for a restart. Toggled cards stay in
  their current Enabled/Disabled section with a pending chip until the restart —
  `sidecar` + `desktop`
- **Slow repositories no longer eat the context budget** — Git context probes
  run in parallel with bounded timeouts, so a slow or remote filesystem cannot
  stall the turn's context collection — `sidecar`
- **Core display redaction stays on** — secret masking in pushed UI output no
  longer depends on the model-result redaction plugin being enabled — `sidecar`

### Fixes

- **Plugin configuration failures are readable** — a corrupted `taco.json`
  returns a structured error instead of an opaque internal one, the desktop
  shows a localized message instead of raw English, and a required secret that
  is explicitly cleared is flagged like any other required field — `sidecar` +
  `desktop`
- **Stale plugin configuration can always be repaired** — keys removed from a
  plugin's schema can be unset through the settings dialog, so leftover values
  no longer leave the configuration permanently invalid — `sidecar`
- **Secret enum fields show their real state** — a configured enum secret now
  shows "configured; leave blank to keep" instead of looking unset — `desktop`
- **Refreshing the checkpoint list clears the previous error** instead of
  showing it alongside the loading spinner — `desktop`
- **The tools panel opens without stalling** — showing a tool's input schema
  loads only the one grammar it needs instead of every bundled syntax
  highlighter, so the panel no longer freezes or fails to open on a cold
  cache — `desktop`
- **Diagnostics polling no longer spawns processes repeatedly** — workspace
  activation probes are cached briefly while the plugins pane is open — `sidecar`

### Breaking changes

- **`disabledExtensions` now also disables directory-discovered extensions** —
  previously it only applied to built-in and npm-installed extensions, and a
  same-named directory extension could shadow a disabled one. If you rely on
  that override, re-enable the entry or rename the directory extension —
  `sidecar`
- **Protocol result types gained required fields** — `ExtensionsStatusResult`
  adds `workspace` / `disabledEntries` / `pendingRestart` and
  `ExtensionStatusEntry` adds `contributions`. The wire change is additive and
  JSON consumers are unaffected, but external TypeScript implementations of
  `@taco-ai/protocol` must populate the new fields — `protocol`

### Upgrade notes

- Upgrade the desktop and the sidecar together (protocol 2.19). The desktop
  replaces an outdated daemon on its own; if you registered the daemon as a
  system service with `taco install` and run the npm packages separately,
  upgrade it with `taco upgrade` or restart it — otherwise the desktop refuses
  the connection and the plugin settings dialog stays unavailable.

## 中文

### 新功能

- **插件拥有独立的配置弹窗** —— 插件详情与设置改为独立弹窗展示。支持的简单类型与枚举
  设置按插件自己的 schema 渲染，字段文案由插件提供多语言版本；保存时只写入改动过的
  字段，重启后生效 —— `sidecar` + `desktop`
- **内置插件支持独立配置** —— Git 上下文、项目清单、OfficeCLI 与输出脱敏插件接入
  校验过的配置与工作区激活诊断。项目在会话中途初始化后也能识别 Git／项目上下文，
  OfficeCLI 的技能与命令自动放行拆分为两个独立选项 —— `sidecar` + `desktop`

### 优化

- **单个插件出错不再拖垮整个工作区** —— 插件运行时支持原子回滚、工作区激活器、
  惰性工具和文件访问声明。加载失败的工具候选会被跳过并记录名字，与内置工具重名的
  候选会被丢弃而不是让所有会话无法启动，一个插件也无法再抹掉另一个插件的文件访问
  声明 —— `sidecar` + `desktop`
- **插件具备分级生命周期与更真实的诊断** —— 工作区与会话激活器带完成事件和确定性
  清理，配置按插件独立校验，状态诊断区分「实际生效的贡献」与「等待重启的变更」。
  切换启用状态的卡片留在原分区并显示待重启标记，直到重启完成 —— `sidecar` + `desktop`
- **缓慢的仓库不再占满上下文预算** —— Git 上下文探测并行执行并收紧超时上限，
  慢速或远程文件系统不会再卡住每轮的上下文收集 —— `sidecar`
- **核心展示脱敏始终生效** —— 推送到界面的内容脱敏不再依赖模型结果脱敏插件是否
  启用 —— `sidecar`

### 修复

- **插件配置失败可读可修** —— `taco.json` 损坏时返回结构化错误而非含糊的内部错误，
  桌面端显示本地化提示而不是英文原文；被显式清空的必填密钥字段与其他必填字段一样
  会给出内联错误 —— `sidecar` + `desktop`
- **残留的过时配置总能修复** —— 已从插件 schema 中移除的键可以在配置弹窗中清除，
  遗留的旧值不会再让配置永远校验失败 —— `sidecar`
- **枚举类型的密钥字段显示真实状态** —— 已配置的枚举密钥现在显示「已配置；留空
  保留原值」，不再看起来像未设置 —— `desktop`
- **刷新检查点列表会清除上一条错误**，不再让旧错误与加载指示同时出现 —— `desktop`
- **工具面板打开不再卡顿** —— 展示工具的输入 schema 时只加载需要的那一个语法
  高亮，而不是全部内置语法，缓存未就绪时面板也不会再打开失败 —— `desktop`
- **诊断轮询不再反复拉起进程** —— 插件面板打开期间，工作区激活探测会短暂缓存
  结果 —— `sidecar`

### 破坏性变更

- **`disabledExtensions` 现在也会禁用目录扫描发现的插件** —— 此前它只作用于内置与
  npm 安装的插件，同名的目录插件可以覆盖被禁用的条目。如果你依赖这种覆盖方式，
  请重新启用该条目或为目录插件改名 —— `sidecar`
- **协议结果类型新增必填字段** —— `ExtensionsStatusResult` 新增
  `workspace` / `disabledEntries` / `pendingRestart`,`ExtensionStatusEntry` 新增
  `contributions`。线上协议为纯增量、JSON 消费方不受影响，但
  `@taco-ai/protocol` 的外部 TypeScript 实现方需要补全新字段 —— `protocol`

### 升级说明

- 请同时升级桌面端与 sidecar（协议 2.19）。桌面端会自动替换版本不匹配的旧
  daemon；如果你用 `taco install` 把 daemon 注册为系统服务并单独运行 npm 包，
  需要 `taco upgrade` 或重启 daemon —— 否则桌面端会拒绝连接，插件配置弹窗不可用。
