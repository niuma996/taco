# v0.1.1 Release Notes

> Released: 2026-08-27
> `desktop-v0.1.1` · `@taco-ai/{protocol,shared,sidecar,cli}@0.1.1`

---

## English

### Features

- Daemon mode under launchd / schtasks + CLI upgrade command — `sidecar` + `cli`
- Scheduler + jobs system with desktop Schedules UI — `sidecar` + `desktop`
- IM messages routed through pinned sessions — `sidecar`
- sidecar.pid upgraded to JSON; reap honors install id — `sidecar` + `desktop` + `cli`
- Desktop auto-update via tauri-plugin-updater — `desktop`

### Improvements

- Chat UI polish: inline code, message outline, persisted sidebar — `desktop`
- Desktop startup: TCC prewarming, EPERM tolerated, packaged CSP allows WASM, workspace list persisted — `desktop`
- Sidecar reliability: login-shell PATH cached, Windows atomicWrite tolerates EPERM, outbound requests carry version — `sidecar`
- Cross-platform stability: LF endings repo-wide, pnpm-lock stable across macOS / Windows — `all`
- Scheduler & shared-layer refactor: unified RPC naming, hardened job lifecycle, dropped dead code — `sidecar` + `shared`
- Debug daemon `$TACO_HOME` isolated from shared install — `sidecar` + `desktop` + `cli`

### Fixes

- "sidecar hello timeout" on `tauri:dev` and dev-boot kill-restart loops — `sidecar` + `desktop`
- Reap path: own vs foreign daemon, wedged-daemon scoped, dev-mode launcher semantics — `desktop` + `sidecar`
- Sidecar diagnostic fields; readiness probes re-attach on replacement — `sidecar`
- Windows onboarding / runtime / window chrome; packaged binary console suppression — `desktop`
- Agent tool cards orphaned by process exit cleaned up — `sidecar`

## 中文

### 新功能

- daemon 模式由 launchd / schtasks 托管，新增 CLI upgrade 子命令 — `sidecar` + `cli`
- 调度器 + 作业系统，桌面 Schedules UI — `sidecar` + `desktop`
- IM 消息路由到 pin 住的会话 — `sidecar`
- sidecar.pid 升级为 JSON；reap 区分本机 / 他机 — `sidecar` + `desktop` + `cli`
- 桌面自动更新走 tauri-plugin-updater — `desktop`

### 优化

- 聊天气泡：内联代码、消息描边、侧栏持久化 — `desktop`
- 桌面启动加固：TCC 预热、EPERM 视为已授权、打包 CSP 允许 WASM、工作区列表持久化 — `desktop`
- sidecar 可靠性：登录 shell PATH 缓存、Windows 原子写入容错 EPERM、出站请求带版本号 — `sidecar`
- 跨平台稳定：全仓库 LF 行尾、pnpm-lock 跨平台稳定 — `all`
- 调度器与共享层重构：统一 RPC 命名、作业生命周期加固、清理死代码 — `sidecar` + `shared`
- debug daemon 的 `$TACO_HOME` 与共享安装隔离 — `sidecar` + `desktop` + `cli`

### 修复

- 修复 `tauri:dev` 上反复出现的 "sidecar hello timeout" 与慢启动 kill-restart 循环 — `sidecar` + `desktop`
- reap 路径：区分本机 / 他机、wedged-daemon 仅杀自家、dev 模式 launcher / detached-daemon 兼容 — `desktop` + `sidecar`
- sidecar 诊断字段映射；进程就绪探针在重启后重新挂接 — `sidecar`
- Windows onboarding / runtime / 窗口标题栏；打包二进制控制台窗口抑制 — `desktop`
- 进程退出后遗留的 agent tool card 自动清理 — `sidecar`
