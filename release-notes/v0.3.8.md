# v0.3.8 Release Notes

> Released: 2026-11-07
> `desktop-v0.3.8` · `@taco-ai/{protocol,shared,sidecar,cli}@0.3.8`

A patch about giving the agent a bit more room to work: file edits can be
rolled back, a separate model can take over the small background jobs, and the
memory behind them is a little more structured.

---

## English

### Features

- **Edits can be rolled back** — checkpoints are grouped by the chat that
  created them, and a reply that changed files offers a one-click undo; files
  changed again afterwards are skipped rather than overwritten —
  `desktop` + `sidecar`
- **An auxiliary model for the small jobs** — session titles and memory
  extraction can run on a separate, cheaper model with its own reasoning
  level; when it is unset or fails, the session's own model takes over —
  `desktop` + `sidecar`
- **Memories carry a bit more context** — a memory body can hold one durable
  theme instead of a single sentence, an entry can show which conversations it
  came from, and the assistant can page back through an earlier conversation
  to check — `desktop` + `sidecar`
- **Memory upkeep settings live in the Memory pane** — the consolidation
  thresholds moved next to the memory list, and archived memories can be
  purged after a retention window — `desktop` + `sidecar`

### Improvements

- **Automatic memory extraction is more selective** — it writes only what it
  can point at, skips a conversation it already saw, and backs off instead of
  retrying on a timer — `sidecar`
- **The list panes read as cards** — Agents, Tools, Skills and Memory show a
  card per entry with its description and tags, and the Tools filters are
  one-click chips — `desktop`
- **The app is easier to drive from the keyboard** — the chat list moves
  with the arrow keys, inputs keep a visible focus ring, approval choices
  are four clearly separated buttons with "Always allow" highlighted, and the
  whole chat row is clickable — `desktop`
- **Permanent deletions are guarded** — every destructive confirmation uses a
  danger-styled button and opens with focus on Cancel, so a reflexive Enter
  no longer destroys anything — `desktop`
- **Secondary text is easier to read** — it now meets WCAG AA contrast in
  both themes, and the smallest labels are no longer microscopic —
  `desktop`

### Fixes

- **In-app updates work on macOS again** — the update archive is now
  packaged in the format the updater expects, and the release pipeline
  verifies it before publishing — `desktop`
- **Subagent replies no longer leak into your IM channel** — a background
  agent's output returns to its parent chat, which decides what (if
  anything) to send you — `sidecar`
- **Stopping a task now really stops the background agent** — cancelling
  while the agent is still starting no longer lets a model run start
  anyway — `sidecar`
- **A shell command that ignores the stop signal no longer hangs** — its
  whole process group is terminated, so leftover background children cannot
  keep the command running — `sidecar`
- **Archived memories are cleaned up on schedule** — memories archived by
  earlier versions now expire based on when they were created — `sidecar`

## 中文

### 新增

- **改动可以回滚** —— 检查点按创建它的聊天分组，助手回复改过文件时提供一键撤销；
  之后又被改过的文件会被跳过，不会被覆盖 —— `desktop` + `sidecar`
- **为小任务单独指定辅助模型** —— 会话标题与记忆提取可以交给另一个更轻量的模型，
  辅助模型还有独立的思考等级；未设置或调用失败时，会自动改用当前会话的主模型 ——
  `desktop` + `sidecar`
- **记忆多带一点上下文** —— 记忆正文可以承载一个完整主题而不只是一句话，条目可以
  显示它来自哪些会话，助手也可以回看历史对话来核对 —— `desktop` + `sidecar`
- **记忆维护设置放在记忆面板里** —— 整理阈值收到了记忆列表旁边，归档后的记忆可按
  保留期自动清理 —— `desktop` + `sidecar`

### 优化

- **后台记忆提取更有选择性** —— 只写有据可依的内容，同一段对话不会重复提取，模型
  服务异常时自动退避，不会反复重试 —— `sidecar`
- **列表面板改为卡片布局** —— Agents、Tools、Skills、Memory 四个面板改为每项一张
  卡片，带描述与标签；Tools 的筛选改为可一键点选的胶囊 —— `desktop`
- **键盘操作更顺畅** —— 会话列表支持方向键导航，输入框恢复焦点环；审批选项拆成
  四个含义清晰的按钮，「始终允许」单独高亮，整行会话都可以点击 —— `desktop`
- **永久删除操作更保险** —— 所有破坏性确认框的确认按钮改为危险色，打开时默认聚焦
  「取消」，回车不会误删 —— `desktop`
- **次要文字更易读** —— 在明暗两种主题下都达到 WCAG AA 对比度，最小字号也不再过小
  —— `desktop`

### 修复

- **macOS 上的应用内更新恢复可用** —— 更新包改为 updater 期望的格式，发布流程还会在
  推送前校验归档内容 —— `desktop`
- **子代理的回复不再串到你的 IM 渠道** —— 后台智能体的产出现在回到父会话，由父会话
  决定要不要发给你 —— `sidecar`
- **停止任务现在真的能停住后台智能体** —— 在智能体还在启动时取消，不会照样发起一次
  模型调用 —— `sidecar`
- **无视停止信号的 shell 命令不再一直挂着** —— 它的整个进程组会被强制结束，残留的
  后台子进程不会再让命令卡住 —— `sidecar`
- **归档的记忆会按期清理** —— 早期版本归档的记忆现在按创建时间正常到期 —— `sidecar`

## Breaking changes

- **Memory consolidation and memory entries changed shape** — the scheduled
  job's `minChanges` and `model` arguments are ignored, consolidation now
  runs on the default model, a memory is a topic rather than a sentence, and
  the length limit moved from 1000 to 2000 characters. Existing files stay
  readable — `sidecar`
- **Restoring a checkpoint now requires that chat to be open** — the other
  groups offer "Open chat" instead — `desktop`
- **The protocol surface grew a little** — `checkpoints.restore` now returns
  a `conflicts` array, `memory.list` entries carry the optional `sources`,
  `explicitlyRequested` and `archivedAt` fields, and a `memory.changed`
  push event was added. Keep the desktop and the sidecar on the same
  release line — `sidecar` + `cli`

## Upgrade notes

- Versions advance `0.3.7 → 0.3.8` across `desktop`, `protocol`, `shared`,
  `sidecar` and `cli`.
- **Memory consolidation now runs on your default model.** If you had a
  dedicated consolidation model configured, point it at the auxiliary model
  setting instead.
- **macOS in-app updates install properly now.** The 0.3.7 updater archive
  was broken, so if 0.3.7 never offered you an update, update once by hand.
- `taco.json` gains two optional keys, `liteModel` and `liteThinkingLevel`,
  for the auxiliary model. Existing config files need no change.
