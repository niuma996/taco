# v0.2.8 Release Notes

> Released: 2026-10-14
> `desktop-v0.2.8` · `@taco-ai/{protocol,shared,sidecar,cli}@0.2.8`

A reliability release: the agent stops being told about tools that don't exist, stops deadlocking on its own compaction, and no longer walks around the permission gate with a `~` in the path. Deleting a session now takes its subagents with it.

---

## English

### Features

- **Write global skills and agents directly** — `write` now reaches `$TACO_HOME/skills/` and `$TACO_HOME/agents/` from a local main session without a permission prompt, so installing a skill no longer requires an approved shell command — `sidecar`

### Improvements

- **Prompts no longer advertise capabilities the harness doesn't have** — they claimed an `edit` parameter that isn't one, read-before-edit enforcement that doesn't exist, tools absent from the catalog, and sequential scheduling for tool calls that run concurrently — `sidecar`
- **Subagents no longer get user-interaction tools** — `agent`, `askUser`, `planEnter` and `planExit` are stripped from child sessions, so a subagent can't ask the user a question it has no way to deliver — `sidecar`
- **Desktop shell tidied into one system** — panes now share surface tiers, heading alignment, and button/modal primitives, so the shell reads as one design instead of a stack of one-offs — `desktop`

### Fixes

- **The permission gate no longer leaks `~`, `@` and `file://` paths** — `write ~/.zshrc` passed the workspace-containment check because the path was compared before pi expanded it — `sidecar`
- **Auto-compaction no longer deadlocks** — compaction scheduled from the idle-owner callback waited on the very lock it already held, so a session past its threshold hung instead of compacting — `sidecar`
- **Stopping a shell command now stops what it started** — surviving grandchildren could hold stdout open and freeze the tool call forever; POSIX now signals the whole process group — `sidecar`
- **Deleting a session now takes its subagents with it** — `session.delete` cascades across the session tree, clearing each one's task store and subagent results instead of orphaning them — `sidecar` + `protocol`

## 中文

### 新功能

- **直接编写全局 skill 与 agent** —— 本地主 session 中 `write` 现在可直接写 `$TACO_HOME/skills/` 与 `$TACO_HOME/agents/`，不再触发权限询问；装一个 skill 不必再绕道请求一次已批准的 shell 命令 — `sidecar`

### 优化

- **prompt 不再宣称 harness 并不具备的能力** —— 此前描述了并不存在的 `edit` 参数、实际并不强制的先读后改、catalog 里没有的工具，以及把并发执行的工具调用说成串行 — `sidecar`
- **子代理不再拿到需要与用户交互的工具** —— `agent`、`askUser`、`planEnter`、`planExit` 已从子 session 剥离，子代理不会再问出一个它根本没有渠道送达的问题 — `sidecar`
- **桌面外壳收敛成一套** —— 各面板现在共用表面层次、标题对齐与按钮/弹窗基元，外壳读起来是一个设计，而不是一堆各自为政的实现 — `desktop`

### 修复

- **权限闸门不再被 `~`、`@`、`file://` 路径绕过** —— `write ~/.zshrc` 之前能通过工作区包含检查，因为路径是在 pi 展开之前比较的 — `sidecar`
- **自动压缩不再死锁** —— 从 idle-owner 回调里排的压缩任务会等它自己已持有的那把锁，超过阈值的 session 因此挂住而非压缩 — `sidecar`
- **停止 shell 命令时，它启动的进程也一起停** —— 残留的孙进程可能占住 stdout，让工具调用永久卡住；POSIX 上现在按进程组整体发信号 — `sidecar`
- **删除会话时会连带删除其子代理** —— `session.delete` 现在级联覆盖整棵会话树，清掉每个会话的任务存储与子代理结果，而不是把它们遗留成孤儿 — `sidecar` + `protocol`

## Upgrade notes

- Workspace versions advance `0.2.7 → 0.2.8` across `desktop`, `protocol`, `shared`, `sidecar`, and `cli`.
- Wire protocol stays at **2.1**. No RPC method, push frame, or schema changed.
- `session.delete` now emits one `session.deleted` frame per session id removed, not just the target. Clients should handle a burst and key each frame to its own session.
- `session.compaction_finished` is now emitted only when a matching `compaction_started` was sent. Pair on the start frame rather than treating a finish as standalone.
- Pi moves `0.86.1 → 0.99.2`, the last release before Pi 1.0 relocates the agent harness out of `pi-agent-core`. The bundled OpenRouter catalog dropped 16 model ids, so a `defaultModel` pointing at one now starts with no default model.
