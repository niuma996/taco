# v0.3.7 Release Notes

> Released: 2026-11-04
> `desktop-v0.3.7` · `@taco-ai/{protocol,shared,sidecar,cli}@0.3.7`

A patch on top of v0.3.6: a channel that cannot start because its dependency is
missing can now be repaired from the app, the desktop no longer races itself
into starting several daemons, and the agent runtime moves to the Pi 1.5 model
stack.

---

## English

### Features

- **A missing channel dependency can be installed from the app** — when a
  WeChat or WeCom channel fails to start because its optional SDK is not
  installed, the failed card in the Channels pane now offers "Install
  dependency and retry". One click installs the dependency and retries the
  channel; a dependency that is already installed can be retried without
  installing anything — `desktop` + `sidecar`

### Improvements

- **The agent runtime moves to the Pi 1.5 model stack** — new models and
  upstream provider and auth fixes now arrive by bumping the dependency, and
  model calls can be recorded as spans and metrics through the harness
  telemetry API — `sidecar`

### Fixes

- **Concurrent workspace opens no longer start several daemons** — the desktop
  app keeps a single owner across the whole startup sequence, so parallel opens
  can no longer race into competing daemons — `desktop`
- **A daemon that loses the startup race no longer removes the winner's
  socket** — the sidecar now confirms who owns the control socket before
  reusing it, and never unlinks a live one — `sidecar`

## 中文

### 新增

- **缺依赖的渠道可以直接在应用里装** —— 微信或企业微信渠道因为没装可选 SDK 而
  起不来时，渠道面板里那张失败卡片上会出现「安装依赖并重试」按钮；点一下就把
  依赖装上并重试这个渠道。依赖已经装好的，可以直接重试，不用再装一遍 ——
  `desktop` + `sidecar`

### 优化

- **Agent 运行时升级到 Pi 1.5 模型栈** —— 新的模型、上游 provider 与鉴权修复
  现在跟着依赖升级一起到位；模型调用也可以通过 harness 的 telemetry API 记录
  成 span 与指标 — `sidecar`

### 修复

- **同时打开多个工作区不再起多个 daemon** —— 桌面端在整个启动流程里保持单一
  归属，并发打开工作区不会再各自拉起一个 daemon 互相抢占 — `desktop`
- **抢输的 daemon 不会再删掉赢家的 socket** —— sidecar 现在会先确认控制 socket
  归谁所有再决定复用，并且绝不删掉还活着的那个 — `sidecar`

## Upgrade notes

- Versions advance `0.3.6 → 0.3.7` across `desktop`, `protocol`, `shared`,
  `sidecar` and `cli`.
- **The Channels pane can install the optional channel dependency for you.**
  You no longer need to open a terminal to install the WeChat or WeCom SDK by
  hand — the app does it, and retries the channel straight away.
- The published sidecar now pulls the Pi harness from npm instead of a local
  tarball. Nothing to do on your side; the dependency arrives with the install.
- Everything else in 0.3.7 is the same as 0.3.6 — see the v0.3.6 notes for what
  is new.
