# v0.4.3 Release Notes

> Released: 2026-11-19
> `desktop-v0.4.3` · `@taco-ai/{protocol,shared,sidecar,cli}@0.4.3`

This release puts the workspace's Git state on screen, and tidies up the
plumbing behind configuration and provider requests.

---

## English

### Features

- **The workspace's Git state is now visible** — a Git status line in the chat
  area shows the current branch, plus the detached HEAD, bare repository and
  "no commits yet" states. The file drawer marks added, modified, deleted,
  renamed and conflicted files, and you can initialize a repository or jump to
  the Git download page from the same place when Git is missing — `sidecar` +
  `desktop`
- **Provider request identity** — a single setting under Providers & Models
  replaces the default `taco/<version>` User-Agent on provider requests —
  `sidecar` + `desktop`

### Improvements

- **One source of truth for workspace configuration** — the layered
  configuration (global, workspace, project), the skill and agent directories
  and the checkpoint stores are resolved through a single routing layer instead
  of several overlapping ones, and checkpoint writes are serialized so two
  sessions saving at the same time no longer race — `sidecar`
- **The agent's configuration writes are bounded** — only the default model,
  thinking level, system prompt, compaction, instructions and command
  permissions can be changed by the agent; anything else is refused before you
  are asked to approve it — `sidecar`
- **The auxiliary model picker matches the main one** — the secondary model
  selector in settings now uses the same menu component as the primary picker —
  `desktop`

### Fixes

- **A resumed session gets the same tools as a fresh one** — reattaching to an
  existing session reconciles its toolset with the current policy, and a tool
  that was temporarily unavailable is retried on the next attach instead of
  being forgotten — `sidecar`
- **The file tree handles the keyboard on its own** — arrow keys and Enter act
  on the row under the cursor instead of the container jumping back to the first
  row — `desktop`
- **Windows works again** — test scripts expand their globs on Windows instead
  of silently matching nothing, the sidecar starts through the real Node
  binary, temporary files land in the OS temp directory, timed-out commands
  kill their whole process tree, and the grep tool normalizes path separators
  — `all`

### Breaking changes

- **The sidecar protocol is now 2.21** — a 2.20 daemon silently drops the
  request-identity field when it is written, so the desktop and the sidecar
  have to be upgraded together — `protocol`

### Upgrade notes

- Upgrade the desktop and the sidecar together (protocol 2.21). The desktop
  replaces an outdated daemon on its own; if you registered the daemon as a
  system service with `taco install` and run the npm packages separately,
  upgrade it with `taco upgrade` or restart it — otherwise the desktop refuses
  the connection.

## 中文

### 新功能

- **工作区的 Git 状态一目了然** —— 聊天区新增 Git 状态行，显示当前分支，以及
  游离 HEAD、裸仓库和「尚无提交」几种状态。文件抽屉会标记新增、修改、删除、
  重命名和冲突的文件；同一处还可以一键初始化仓库，或在未安装 Git 时跳转到
  官方下载页 —— `sidecar` + `desktop`
- **模型服务看到的请求标识可配置** —— 「服务商与模型」下新增一个设置项，发往模型
  服务的请求不再携带默认的 `taco/<版本号>` 标识 —— `sidecar` + `desktop`

### 优化

- **工作区配置只有一个来源** —— 分层配置（全局、工作区、项目）、技能与智能体
  目录、检查点存储统一走同一套路由，不再由多处重叠逻辑各算一遍；检查点写入
  也改为串行，两个会话同时保存不再互相踩踏 —— `sidecar`
- **模型能改动的配置项被收窄** —— 默认模型、思考级别、系统提示词、上下文压缩、
  指令与命令权限之外的字段，在向你请求确认之前就会被拒绝 —— `sidecar`
- **辅助模型选择器与主选择器一致** —— 设置中的次要模型选择器改用与主选择器
  相同的菜单组件 —— `desktop`

### 修复

- **恢复的会话与新建会话拥有同样的工具** —— 重新接入已有会话时，工具列表会与
  当前策略重新对齐；暂时不可用的工具会在下次接入时重试，不再被直接遗忘 ——
  `sidecar`
- **文件树自己处理键盘操作** —— 方向键与回车作用于光标所在行，容器不再跳回
  第一行 —— `desktop`
- **Windows 重新可用** —— 测试脚本在 Windows 上正确展开通配符，不再静默匹配不到
  任何文件；sidecar 通过真实的 Node 可执行文件启动；临时文件落在系统临时目录；
  超时的命令会结束整个进程树；grep 工具统一路径分隔符 —— `all`

### 破坏性变更

- **sidecar 协议升级到 2.21** —— 2.20 的 daemon 会静默丢弃写入的请求标识字段，
  桌面端与 sidecar 必须一起升级 —— `protocol`

### 升级说明

- 请同时升级桌面端与 sidecar（协议 2.21）。桌面端会自动替换版本不匹配的旧
  daemon；如果你用 `taco install` 把 daemon 注册为系统服务并单独运行 npm 包，
  需要 `taco upgrade` 或重启 daemon —— 否则桌面端会拒绝连接。
