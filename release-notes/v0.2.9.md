# v0.2.9 Release Notes

> Released: 2026-10-16
> `desktop-v0.2.9` · `@taco-ai/{protocol,shared,sidecar,cli}@0.2.9`

The runtime release: a subagent can now work inside your own Claude Code CLI, the agents that give a subagent its job can be written from the desktop, and a session that's still working no longer looks like it's done.

---

## English

### Features

- **Subagents can run on your own Claude Code CLI** — give an agent the `claude-code` runtime and its work is handed to the `claude` you already have installed and signed in to, instead of running inside taco. You pick which tools it has and how it asks permission, and you watch it work live in the panel — `sidecar`
- **You can create, edit and delete agents from the desktop** — no more hand-writing agent files by hand: the agents panel does it, a saved change takes effect right away in every open workspace without a restart, and an agent that's just a set of tools with no personality of its own can say so instead of being left with a blank prompt — `sidecar` + `desktop`
- **Task and subagent panels open themselves, once per run** — when a turn spawns a subagent or starts a task list, the panel comes up on its own so you don't have to go looking for it; reopening a session that was already running stays quiet, because its work was already underway — `desktop`

### Improvements

- **The interface got a visual pass** — the app now reads as one design rather than a stack of separately-built panels — `desktop`

### Fixes

- **A session that is still working no longer looks like it finished** — switching away mid-run and coming back, or starting a new chat while another session was busy, both marked the running session as stopped even though it carried on; it now stays running until the run actually ends — `desktop`
- **The CLI stops instead of taking over another install's daemon** — launching taco while a live daemon from a different checkout or bundle was running used to quietly kill it, leaving you connected to an old build with nothing to explain it; it now tells you what's in the way and how to fix it — `cli`

## 中文

### 新功能

- **子代理可以跑在你自己的 Claude Code CLI 里** —— 给一个 agent 选上 `claude-code` 运行方式，它的工作就交给你已经装好、已经登录的那个 `claude` 去跑，而不是关在 taco 里。工具集和权限方式按 agent 自己配，进度实时显示在面板上 — `sidecar`
- **agent 可以在桌面里直接创建、编辑和删除** —— 不用再手写 agent 文件：agents 面板里改完立刻生效，每个开着的 workspace 都会用上，无需重启；如果一个 agent 只是套工具、本身没有角色，现在可以明确声明，而不是留一段空 prompt — `sidecar` + `desktop`
- **任务与子代理面板每次 run 自动打开一次** —— 这一轮触发了子代理或启用了任务列表，面板自己就出来了，不用你去找；重新打开一个本来就在跑的 session 则不会打扰你，因为它的活儿早就在干了 — `desktop`

### 优化

- **整个界面做了一遍视觉统一** —— 现在看起来是一个完整的设计，而不是一堆各自拼起来的面板 — `desktop`

### 修复

- **仍在工作的会话不再显示为已结束** —— 跑到一半切走再切回来、或者在别的会话正忙时开新会话，都会把还在跑的会话标成已停止，尽管它其实一直在继续；现在它会一直显示运行中，直到这轮真的结束 — `desktop`
- **CLI 不再接管别的安装的 daemon，而是停下来** —— 当另一个 checkout 或 bundle 的 daemon 还在跑时启动 taco，之前会悄悄把它杀掉，于是你连上的是旧构建，却没有任何提示；现在它会告诉你挡路的是什么、该怎么处理 — `cli`

## Upgrade notes

- Workspace versions advance `0.2.8 → 0.2.9` across `desktop`, `protocol`, `shared`, `sidecar`, and `cli`.
- Wire protocol stays at **2.1**. Two methods are added — `agents.write` and `agents.delete`. Agent tool details gain `aborted` (stopped on purpose) and `error` (never started) variants, so a client should stop reading them as one red state; the `error` variant carries no `subSessionId`.
- The Claude Code runtime is opt-in and its SDK is deliberately not bundled — it would drag a ~240 MB platform binary into every install. Until you install it, a `claude-code` agent can't start:

  ```bash
  npm install --prefix ~/.taco/vendor --omit=optional @anthropic-ai/claude-agent-sdk
  ```
- Agents can only be written or deleted under `$TACO_HOME/agents`; built-in and workspace-local ones stay read-only.
