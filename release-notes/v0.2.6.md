# v0.2.6 Release Notes

> Released: 2026-09-20
> `desktop-v0.2.6` · `@taco-ai/{protocol,shared,sidecar,cli}@0.2.6`

Session titles now derive from an LLM summary instead of a truncated first message, manual Compact is sized from actual session usage instead of the auto-compact budget, and skill hot reload no longer forces a KV-cache miss when nothing actually changed. The title bar gains quick language/theme switches, and the Tauri shell now runs clippy and tests on every PR.

---

## English

### Features

- **Session titles derived from an LLM summary** — titles now carry provenance (placeholder → LLM summary → explicit rename), with a summary re-derived after each completed run and pushed live via a new `session.renamed` event; a manual rename is terminal and can no longer be overwritten by a later summary — `sidecar` + `protocol` + `desktop`
- **Language and theme shortcuts in the title bar** — quick-access menus for language and theme sit at the right edge of the topbar, with extra padding on Windows/Linux to clear the native window controls — `desktop`

### Improvements

- **Rust CI on every PR** — the Tauri shell's clippy and `cargo test` now run on every PR instead of only at release-tag time, catching regressions earlier — `all`

### Fixes

- **Manual Compact sized from current usage, not the auto-compact budget** — Compact reused a `keepRecentTokens` derived from the model's context window, so a session far below the auto threshold retained everything and produced an empty summary; it now keeps 30% of current usage and only refuses when there's nothing to summarize — `sidecar`
- **Skill hot reload no longer rebuilds an unchanged system prompt** — a no-op rescan (editor touch, unrelated file change in the skills directory) was unconditionally replacing the system prompt, forcing a KV-cache miss on every session attached afterward even when the rendered skill list was byte-identical — `sidecar`

## 中文

### 新功能

- **会话标题改由 LLM 摘要派生** —— 标题现在带有来源信息(占位截断 → LLM 摘要 → 手动重命名),每次运行结束后会重新生成摘要,并通过新增的 `session.renamed` 事件实时推送;手动重命名是终态,之后的摘要不会再覆盖它 — `sidecar` + `protocol` + `desktop`
- **标题栏新增语言与主题快捷入口** —— 语言和主题的快捷菜单固定在顶栏右侧,Windows/Linux 上额外留白以避开系统窗口控件 — `desktop`

### 优化

- **Rust CI 覆盖到每个 PR** —— Tauri 客户端的 clippy 与 `cargo test` 现在每个 PR 都会跑,不再只在打 release tag 时才跑,能更早发现回归 — `all`

### 修复

- **手动 Compact 改按当前用量计算,不再套用自动压缩的预算** —— Compact 之前复用了按模型上下文窗口推算的 `keepRecentTokens`,导致远低于自动阈值的会话也会保留全部内容并生成空摘要;现在改为保留当前用量的 30%,只有在确实无内容可摘要时才拒绝执行 — `sidecar`
- **Skill 热重载不再对无变化的系统提示词做重建** —— 一次空操作的重扫描(编辑器触碰文件、skills 目录里无关文件变动)会无条件替换系统提示词,即便渲染出的 skill 列表逐字节相同,也会让此后挂载的每个会话都撞上一次 KV 缓存失效 — `sidecar`

## Upgrade notes

- Workspace versions advance `0.2.5 → 0.2.6` across `desktop`, `protocol`, `shared`, `sidecar`, and `cli`. Keep the desktop and sidecar on the same release line, as before.
- Wire protocol stays at 2.1, extended with a new `session.renamed` push event; existing consumers that ignore unknown push types are unaffected.
- Sessions titled before this release have no recorded title source — the placeholder path treats that as owned by someone else, while the summary path may still replace it on the next completed run.
