# v0.3.4 Release Notes

> Released: 2026-10-31
> `desktop-v0.3.4` · `@taco-ai/{protocol,shared,sidecar,cli}@0.3.4`

A release about finding things again: the sidebar can search every session in a
workspace, and the file-tool policy is now decided in one place.

---

## English

### Features

- **Search your sessions** — the sidebar searches the whole workspace, not just
  the page you happen to have loaded — `desktop` + `sidecar`
- **A new chat button in the sidebar** — start a new session without leaving
  the list — `desktop`

### Improvements

- **Approvals open next to the notification bell** — pending command approvals
  no longer cover the chat, and resolving one keeps the panel open while the
  others are still queued — `desktop`

### Fixes

- **A toolset change reaches every open session** — an MCP server or a skill
  added mid-conversation now shows up in all of them — `sidecar`
- **Tools no longer disappear mid-turn** — a tool the model loaded on demand
  stays available — `sidecar`
- **Chat sessions respect the file-tool policy** — a session that denies file
  tools no longer loads them, and the model is told which tools are
  unavailable — `sidecar`

### Breaking changes

- **Wire protocol 2.6 → 2.7** — `session.list` takes an optional `query`. Keep
  the desktop and the sidecar on the same release line; a newer desktop
  refuses an older daemon at startup — `sidecar` + `desktop`
- **The typed client takes one object per call** — `@taco-ai/shared` methods
  take a params object now:
  `client.sessionPrompt({ workspace, sessionId, text })` — `shared`

## 中文

### 新功能

- **搜索会话** —— 侧边栏现在搜索整个工作区，而不只是当前加载的那一页 — `desktop` + `sidecar`
- **侧边栏新增新会话按钮** —— 不用离开会话列表就能开始一段新对话 — `desktop`

### 优化

- **审批改为在通知铃旁打开** —— 待处理的命令审批不再挡住对话窗口；处理掉其中
  一条时，面板会继续留着，其余请求还在排队 — `desktop`

### 修复

- **工具集变更会送达所有打开的会话** —— 对话进行到一半新增的 MCP 服务或技能，
  现在每个会话都能用上 — `sidecar`
- **工具不会再在对话中途消失** —— 模型按需加载的工具会一直保留 — `sidecar`
- **聊天会话会遵守文件工具策略** —— 策略禁止文件工具的会话不再加载这些工具，
  模型也会明确知道哪些工具不可用 — `sidecar`

### 破坏性变更

- **线路协议 2.6 → 2.7** —— `session.list` 新增可选的 `query`。请让桌面端与
  sidecar 保持同一版本线；新版桌面端会在启动时拒绝旧版 daemon — `sidecar` + `desktop`
- **类型化客户端每个方法只收一个对象** —— `@taco-ai/shared` 的方法现在统一接收
  参数对象：`client.sessionPrompt({ workspace, sessionId, text })` — `shared`

---

## Upgrade notes

- Versions advance `0.3.3 → 0.3.4` across `desktop`, `protocol`, `shared`,
  `sidecar` and `cli`.
- Wire protocol advances `2.6 → 2.7`. Keep the desktop and the sidecar on the
  same release line — a registered system-service daemon can outlive a desktop
  upgrade.
- The sidebar search needs sidecar `0.3.4`.
- `@taco-ai/shared` breaks: `client.sessionPrompt(workspace, sessionId, text)`
  becomes `client.sessionPrompt({ workspace, sessionId, text })`, and the rest
  of the facade takes the same shape.
