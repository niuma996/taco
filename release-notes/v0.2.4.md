# v0.2.4 Release Notes

> Released: 2026-09-17
> `desktop-v0.2.4` · `@taco-ai/{protocol,shared,sidecar,cli}@0.2.4`

File preview now renders HTML and exposes an open-in-browser button, tool cards become layout-overridable per tool, and the Windows installer asks the running daemon to shut down before swapping its binary.

---

## English

### Features

- **HTML rendering + open-in-browser in file preview** — preview popup now renders HTML inline and adds an explicit "open in system viewer" affordance, so the path-to-browser round-trip no longer requires leaving the app or hand-copying paths — `desktop`
- **Draggable debug dock + subagent panel polish** — the debug dock is now draggable instead of pinned to a corner, and the subagent panel gains a message-meta row plus visual polish to match the rest of the right rail — `desktop`

### Improvements

- **Per-tool card region overrides + JSON-free default summary** — tool card layout is overridable per tool, so one tool's awkward region can be reshaped without polluting the default for the others; the default summary drops its JSON tail so cards read as prose first — `desktop`
- **Updater pubkey embedded as base64 of the whole .pub file** — the updater bundle no longer carries the raw `.pub` bytes inline; the build embeds the base64 of the entire file, so a tampered or truncated key fails the same way on every platform instead of silently differing per-architecture — `desktop`
- **Skill diagnostics routed through one logging seam** — every skill load / hot-reload / extension diagnostics path now goes through a single logging helper, so log filtering and forwarding are configured in one place — `sidecar`

### Fixes

- **Windows installer stops the running daemon before overwriting its binary** — the installer now asks the daemon to shut down before swapping the `.exe`, so a long-running install no longer leaves the user with a stale or partially-updated sidecar — `desktop` + `cli`

- **Debug dock 可拖拽 + subagent 面板打磨** —— debug dock 可拖动，不再锁死角落；subagent 面板新增 message meta 行与视觉细节，与右栏风格统一 — `desktop`

### 优化

- **工具卡片按 tool 单独覆写区域 + 默认 summary 去掉 JSON** —— 工具卡片布局支持按 tool 单独覆写，单个 tool 的怪异区域可以单独重塑而不污染其他 tool 的默认；默认 summary 去掉 JSON 尾巴，工具卡片先以散文呈现 — `desktop`

## Upgrade notes

- Workspace versions advance `0.2.3 → 0.2.4` across `desktop`, `protocol`, `shared`, `sidecar`, and `cli`. Keep the desktop and sidecar on the same release line, as before.
- Wire protocol stays at 2.1 — no breaking change for downstream consumers.
- File preview is now HTML-aware: HTML files open with rendering inside the preview popup, and any file can be opened in the system viewer via the new button. Plaintext / Markdown / code files are unchanged.
- The Windows daemon-stop fix is installer-side only; existing installs are not affected at runtime, but new installs (or in-place updates) on Windows will close the running daemon before swapping the binary.
- The updater pubkey is now base64-encoded at build time. Local builds pick this up automatically; release builds keep using the embedded key as before.
- `max_runs` and `max_consecutive_failures` defaults from 0.2.2 / 0.2.3 are unchanged.
