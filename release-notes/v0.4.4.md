# v0.4.4 Release Notes

> Released: 2026-11-26
> `desktop-v0.4.4` · `@taco-ai/{protocol,shared,sidecar,cli}@0.4.4`

This release brings Git worktrees into the product, lets you rename the
assistant, and takes some waiting out of the cold start.

---

## English

### Features

- **Worktrees are managed from the desktop** — a new Worktrees dialog lists the
  worktrees of a repository, creates one from a base branch, removes it, and
  switches the main working directory between them; removing a worktree keeps
  its branch and session history, and a record whose checkout is gone can be
  cleared on its own — `sidecar` + `desktop`
- **The agent can hand work over to a worktree** — the agent opens a worktree
  and moves the current work into it, and the desktop follows the handover —
  `sidecar` + `desktop`
- **The assistant can be renamed** — a `productName` field in
  `$TACO_HOME/taco.json` replaces the name the assistant uses for itself; the
  agent cannot change it on its own — `sidecar`
- **Queued steering messages can be sent as one batch** — messages queued while
  the assistant is running are sent together, and they can also interrupt the
  running turn and go out immediately — `desktop`
- **Deleting a chat is protected** — a chat that is running a turn cannot be
  deleted and the menu explains why; deleting the chat you are looking at
  lands you on the new-chat view — `desktop`

### Improvements

- **The cold start is faster** — the session metadata index is persisted per
  workspace, so the daemon no longer rescans every session file on each start,
  and the desktop reads its workspace configuration in a single round trip —
  `sidecar` + `desktop`
- **The sidebar lists 10 sessions per group by default** — `protocol` +
  `desktop`
- **Command approval covers more read-only commands** — automatic approval
  accepts safe path patterns such as `wc -l src/*.ts`, and the permissions
  settings spell out what manual and automatic approval each cover — `sidecar` +
  `desktop`

### Fixes

- **grep and glob validate their search paths** — a path outside the workspace
  is refused, and grep accepts a single file as its target — `sidecar`
- **The desktop no longer shows an empty session list while it loads** —
  `desktop`
- **Updating the desktop restarts it cleanly** — `desktop`
- **Malformed configuration reports what is wrong** — `sidecar`
- **Worktree changes are serialized and recoverable** — concurrent changes in
  different processes no longer overlap, an interrupted removal recovers, and
  ownership is reconciled — `sidecar` + `desktop`

### Breaking changes

- **The sidecar protocol is now 2.26** — 2.22 adds the worktree methods and
  2.26 the `productName` field, which a 2.21 daemon silently drops on
  `settings.write`; the desktop and the sidecar have to be upgraded together —
  `protocol`

### Upgrade notes

- Upgrade the desktop and the sidecar together (protocol 2.26). The desktop
  replaces an outdated daemon on its own; if you registered the daemon as a
  system service with `taco install` and run the npm packages separately,
  upgrade it with `taco upgrade` or restart it — otherwise the desktop refuses
  the connection.

## 中文

### 新功能

- **工作树可在桌面端管理** —— 新增「工作树」对话框，可以列出仓库的工作树、
  从基础分支新建、删除，并在主工作目录与工作树之间切换；删除工作树会保留对应
  分支与会话历史，工作目录已丢失的记录可以单独清除 —— `sidecar` + `desktop`
- **智能体可以把工作交接给工作树** —— 智能体能新建工作树并把当前工作移交过去，
  桌面端会跟随这次交接 —— `sidecar` + `desktop`
- **助手可以改名** —— 在 `$TACO_HOME/taco.json` 里设置 `productName`，助手在
  提示词中的自称随之改变；模型不能自行修改该字段 —— `sidecar`
- **排队的插话消息可以一次发出** —— 助手运行期间排队的消息合并成一批发送，
  也可以打断当前回合立刻发出 —— `desktop`
- **删除聊天有保护** —— 正在运行回合的聊天不能删除，菜单会说明原因；删掉当前
  打开的聊天后会回到新聊天页 —— `desktop`

### 优化

- **冷启动更快** —— 会话元数据索引按工作区落盘，daemon 不再每次启动都重扫全部
  会话文件；桌面端读取工作区配置也合并成一次调用 —— `sidecar` + `desktop`
- **侧边栏每组默认显示 10 个会话** —— `protocol` + `desktop`
- **命令审批覆盖更多只读命令** —— 自动审批认可 `wc -l src/*.ts` 这类安全的路径
  写法，权限控制里也分别说明手动审批与自动审批各管什么 —— `sidecar` + `desktop`

### 修复

- **grep 与 glob 会校验搜索路径** —— 工作区之外的路径被拒绝，grep 也支持直接
  搜索单个文件 —— `sidecar`
- **桌面端不再在加载时闪出空会话列表** —— `desktop`
- **桌面端更新后能正常重启** —— `desktop`
- **配置格式错误会说明原因** —— `sidecar`
- **工作树变更可串行、可恢复** —— 不同进程里的并发变更不再互相踩踏，中断的删除
  能够恢复，归属也会重新对账 —— `sidecar` + `desktop`

### 破坏性变更

- **sidecar 协议升级到 2.26** —— 2.22 增加工作树相关方法，2.26 增加
  `productName` 字段（2.21 的 daemon 会在 `settings.write` 时静默丢弃它）；
  桌面端与 sidecar 必须一起升级 —— `protocol`

### 升级说明

- 请同时升级桌面端与 sidecar（协议 2.26）。桌面端会自动替换版本不匹配的旧
  daemon；如果你用 `taco install` 把 daemon 注册为系统服务并单独运行 npm 包，
  需要 `taco upgrade` 或重启 daemon —— 否则桌面端会拒绝连接。
