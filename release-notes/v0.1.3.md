# v0.1.3 Release Notes

> Released: 2026-09-04
> `desktop-v0.1.3` · `@taco-ai/{protocol,shared,sidecar,cli}@0.1.3`

---

## English

### Features

- Mermaid fenced code blocks render as diagrams by default, with a header toggle to flip back to source — `desktop`
- WeCom aibot channel with credential bind flow and hardened reconnect lifecycle — `sidecar` + `desktop`
- `llmDumpToFile` setting in Debug tab tees `[taco:llm]` lines from the sidecar stderr reader to `$TACO_HOME/logs/llm-dump.log` — `desktop`
- Plan-mode directive and explorer subagent now nudge models to emit `flowchart` / `sequenceDiagram` blocks for complex traces — `sidecar`

### Improvements

- Code-block language tag in the header survived end-to-end through shiki via a transformer; previous rehype-plugin tagging was discarded — `desktop`
- `settings.write` fans out to every `SidecarServer` in the daemon, so updates reach the live child without restart — `sidecar`
- Control server error listener attached after bind to avoid startup races — `sidecar`
- CLI resolves the sidecar runtime from `dist/` in dev checkouts, not from `src/` — `cli`

### Fixes

- Stale-code daemon is reaped instead of reused, with a ping/pong `sidecar_version` check — `desktop` + `cli`
- NSIS installer preinstall hook kills any leftover sidecar daemon before upgrade — `desktop`
- Shared `after(closeServer)` in control-node test wrapped in an arrow to avoid stale capture — `shared`

## 中文

### 新功能

- Mermaid 代码块默认渲染为流程图，header 切换按钮切回源码视图 — `desktop`
- WeCom aibot 渠道，支持凭据绑定流程与加固的重连生命周期 — `sidecar` + `desktop`
- Debug tab 新增 `llmDumpToFile` 开关，将 `[taco:llm]` 行同步写入 `$TACO_HOME/logs/llm-dump.log` — `desktop`
- Plan 模式指令和 explorer 子代理提示模型在复杂追踪时输出 `flowchart` / `sequenceDiagram` — `sidecar`

### 优化

- 代码块语言标签通过 shiki transformer 端到端透传到 header；先前 rehype 插件写在被丢弃的节点上 — `desktop`
- `settings.write` 广播到 daemon 内全部 `SidecarServer`，子进程无需重启即可收到更新 — `sidecar`
- 控制服务器 error listener 在 bind 完成后挂接，避免启动竞态 — `sidecar`
- CLI 在开发 checkout 中从 `dist/` 解析 sidecar 运行时而非 `src/` — `cli`

### 修复

- 过期代码的 daemon 被回收而非复用，ping/pong 用 `sidecar_version` 判定 — `desktop` + `cli`
- NSIS 安装包 preinstall 钩子在升级前清理残留 sidecar 守护进程 — `desktop`
- shared `controlNode` 测试中 `after(closeServer)` 改写为箭头以避免 stale capture — `shared`
