# v0.3.5 Release Notes

> Released: 2026-11-04
> `desktop-v0.3.5` · `@taco-ai/{protocol,shared,sidecar,cli}@0.3.5`

A release about keeping score of the work that happens while you are not
looking: background runs and scheduled fires are now recorded, visible, and
delivered.

---

## English

### Features

- **A "Background work" pane** — background subagents and scheduled fires are
  recorded, so you can see them all in one place: what is running, what needs
  attention, what has finished — `desktop` + `sidecar`
- **A run history for every schedule** — each schedule opens a History dialog
  with its recent runs: when they ran, how long they took, how they ended, and
  the answer they produced — `desktop` + `sidecar`
- **Background answers reach your chat reliably** — the result is kept with the
  record and delivered to your channel with retries, and a daemon restart in
  the middle of a delivery picks up where it left off — `sidecar`
- **A read-only `ls` with a path pattern no longer asks for approval** — in a
  local automatic session with no deny rules, `ls src/*` simply runs — `sidecar` + `desktop`
- **MCP servers load on demand** — a workspace no longer waits for every MCP
  server to connect at startup, and adding or removing one no longer asks for
  a restart — `sidecar`
- **Background runs get a time limit and a heads-up** — an agent profile can
  set a timeout in minutes, the agent is told when it is close to that limit,
  and a timeout reads differently from a stop you asked for — `sidecar` + `desktop`
- **A read-only subagent cannot write files** — the tools an agent profile
  declares are now a hard boundary, and a read-only agent is told up front
  that it cannot write — `sidecar`

### Improvements

- **The right panel takes a share of the chat area** — 30% by default, never
  more than half — instead of a fixed width, so it behaves the same on a wide
  display and a narrow one — `desktop`
- **A scheduled fire is recorded, and settles honestly** — a prompt that
  joined a turn already running is reported as merged, and a run you stopped
  is reported as stopped rather than failed — `sidecar`
- **The schedules list is one line per schedule** — icon actions, a "last run"
  column, and a warning when a schedule retired itself after too many runs or
  too many failures — `desktop`
- **MCP servers are shared where it is safe** — HTTP servers are shared between
  workspaces, while each IM workspace keeps its own MCP connection private —
  `sidecar`
- **The desktop follows the system's "reduce motion" setting** — and panel
  opens, height collapses and icon swaps are now animated — `desktop`

### Fixes

- **A failed background subagent shows as failed** — and keeps its session, so
  the history stays reachable — `desktop` + `sidecar`
- **A schedule's run history survives a restart** — and a run that hangs can no
  longer lock the schedule forever — `sidecar`
- **The panel width transition no longer lags** — dragging, resizing and the
  keyboard all move it at the same speed — `desktop`
- **The screen reader announces the panel's real range** — and the schedule
  actions stay in view — `desktop`

### Breaking changes

- **Wire protocol 2.7 → 2.10** — the desktop refuses an older daemon, so keep
  the desktop and the sidecar on the same release line. The new surface is
  `work.list`, `work.get` and `work.retryDelivery`, plus a `work.changed`
  push — `sidecar` + `desktop`
- **MCP config changes no longer report a restart** — `mcp.createConfig`,
  `updateConfig` and `deleteConfig` return `requiresRestart: false`; it used
  to be `true` — `sidecar`
- **Agent profiles get a timeout and a higher turn cap** — `agents.write`
  accepts `timeoutMinutes` (1–600) and `maxTurns` up to 500 (was 200);
  `agents.list` and `agents.read` return `timeoutMinutes` — `sidecar` + `desktop`
- **A work record's session moved** — read `WorkSummary.sessionId`;
  `parentSessionId` remains as a deprecated alias — `sidecar`
- **A schedule's history can now contain a running entry** — `jobs.history`
  reports a fire that is still going, not only finished ones — `sidecar`
- **`@taco-ai/protocol` exports more value lists** — `THINKING_LEVELS`,
  `CUSTOM_PROVIDER_APIS` and `MCP_TRANSPORT_KINDS` are public constants now;
  the values they hold are unchanged — `shared`

## 中文

### 新功能

- **「后台工作」面板** —— 后台子代理与定时触发都会被记录下来，你可以在一处看清：
  哪些正在跑、哪些需要处理、哪些已经结束 — `desktop` + `sidecar`
- **每个定时任务都有运行历史** —— 点开「历史」就能看到最近几次运行：什么时候跑的、
  跑了多久、结果如何、给出了什么答案 — `desktop` + `sidecar`
- **后台结果能可靠地送回聊天** —— 结果随记录一起保存，再带重试地发到你的聊天
  渠道；投递途中 daemon 重启，也会接着上次发到的地方继续 — `sidecar`
- **只读 `ls` 加路径通配不再需要批准** —— 本地自动模式且没有拒绝规则时，
  `ls src/*` 会直接执行 — `sidecar` + `desktop`
- **MCP 服务按需加载** —— 工作区启动不再等所有 MCP 服务连上，添加或删除 MCP
  服务也不再需要重启 — `sidecar`
- **后台任务有超时，也会提前得到提醒** —— 代理配置里可以设定分钟数上限，接近
  上限时代理会收到提示；超时与「你手动停止」也能区分开 — `sidecar` + `desktop`
- **只读子代理写不了文件** —— 代理配置里声明的工具列表现在是一条硬边界，只读
  代理一开始就知道自己不能写文件 — `sidecar`

### 优化

- **右侧面板按聊天区的比例分配宽度** —— 默认 30%，最多不超过一半 —— 不再是固定
  像素宽，宽屏和窄屏下的表现一致 — `desktop`
- **定时触发会被记录，也会如实收尾** —— 拼进已经在跑的那一轮的提示，会显示为
  「已合并」；被你停掉的运行，会显示为「已停止」而不是「失败」 — `sidecar`
- **定时任务列表一行一条** —— 行内改成图标操作，多了「上次运行」一列；运行次数
  或失败次数超限而自动停用时，会说明原因 — `desktop`
- **MCP 服务在安全的地方共享** —— HTTP 类服务在多个工作区之间共用，IM 工作区
  各自的 MCP 连接保持独立 — `sidecar`
- **桌面端跟随系统的「减弱动态效果」设置** —— 面板展开、折叠与图标切换也补上了
  过渡动画 — `desktop`

### 修复

- **失败的后台子代理会显示为失败** —— 并保留会话，历史仍然可以找回 — `desktop` + `sidecar`
- **定时任务的运行历史能跨重启保留** —— 卡住不返回的运行，也不会再永久占住这个
  任务 — `sidecar`
- **面板宽度的过渡不再拖后腿** —— 拖动、缩放与键盘操作，速度保持一致 — `desktop`
- **读屏软件会播报面板的真实范围** —— 定时任务的行内操作也不会被挤出视野 — `desktop`

### 破坏性变更

- **线路协议 2.7 → 2.10** —— 新版桌面端会拒绝旧版 daemon，请让桌面端与 sidecar
  保持同一版本线。新增 `work.list`、`work.get`、`work.retryDelivery` 三个方法，
  以及 `work.changed` 推送 — `sidecar` + `desktop`
- **MCP 配置变更不再提示需要重启** —— `mcp.createConfig`、`updateConfig` 与
  `deleteConfig` 现在返回 `requiresRestart: false`，此前是 `true` — `sidecar`
- **代理配置支持超时，轮数上限也更高了** —— `agents.write` 新增 `timeoutMinutes`
  （1–600），`maxTurns` 上限从 200 提到 500；`agents.list` 与 `agents.read` 会
  返回 `timeoutMinutes` — `sidecar` + `desktop`
- **工作记录的会话字段换名** —— 请读 `WorkSummary.sessionId`；`parentSessionId`
  暂时保留为兼容别名 — `sidecar`
- **定时任务的历史里可能出现「运行中」条目** —— `jobs.history` 现在会报告尚未
  结束的触发，而不只是已完成的 — `sidecar`
- **`@taco-ai/protocol` 导出更多取值表** —— `THINKING_LEVELS`、
  `CUSTOM_PROVIDER_APIS` 与 `MCP_TRANSPORT_KINDS` 成为公开常量，取值本身不变 — `shared`

## Upgrade notes

- Versions advance `0.3.4 → 0.3.5` across `desktop`, `protocol`, `shared`,
  `sidecar` and `cli`.
- Wire protocol advances `2.7 → 2.10`. Keep the desktop and the sidecar on the
  same release line — a registered system-service daemon can outlive a desktop
  upgrade.
- The background work pane, the schedule history and the agent timeout need
  sidecar `0.3.5`.
