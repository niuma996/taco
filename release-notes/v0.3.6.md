# v0.3.6 Release Notes

> Released: 2026-11-04
> `desktop-v0.3.6` · `@taco-ai/{protocol,shared,sidecar,cli}@0.3.6`

A patch on top of v0.3.5: the sidecar no longer refuses to start on a machine
that does not have the optional channel SDKs installed.

---

## English

### Fixes

- **The sidecar starts without the optional channel SDKs** — the WeChat and
  WeCom SDKs are now loaded on demand, so a machine that never installed them
  runs the sidecar as usual, and only hears about the missing SDK when it
  actually creates that channel — `sidecar`

---

## 中文

### 修复

- **没装可选渠道 SDK 的机器也能启动 sidecar** —— 微信与企业微信的 SDK 改成按需
  加载，没装这两个可选依赖的机器照常启动；只有真正去创建那个渠道时，才会提示
  缺少 SDK — `sidecar`

---

## Upgrade notes

- Versions advance `0.3.5 → 0.3.6` across `desktop`, `protocol`, `shared`,
  `sidecar` and `cli`.
- **If you installed 0.3.5, please move to 0.3.6.** The sidecar in 0.3.5
  loaded the optional channel SDKs while starting up, so it could refuse to
  start at all on a machine without them. The desktop app shipped the same
  sidecar, so the desktop build needs the update too.
- Everything else in 0.3.6 is the same as 0.3.5 — the feature set is
  unchanged; see the v0.3.5 notes for what is new.
