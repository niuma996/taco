# Worktree D6 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Coordinate managed worktree mutations across processes, repair stale metadata on repository access, and expose safe explicit cleanup.

**Architecture:** Keep the current common-directory in-process queue and add an owner-token lock directory around every Git and metadata mutation. Reconciliation is a read-triggered, identity-checked pass that marks stale records orphaned without deleting anything. Cleanup selects only verified managed checkouts and delegates each deletion to the existing guarded removal path.

**Tech Stack:** TypeScript, Node `node:test`, TypeBox, NDJSON RPC, pnpm.
